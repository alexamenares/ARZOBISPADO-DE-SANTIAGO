CÓMO LLEVARLO AL OTRO COMPUTADOR
1. Copia el ZIP RedPatrimonioReligioso_MidFi.zip y descomprímelo en una carpeta nueva.
2. En Android Studio, usa Open y selecciona RedPatrimonioReligioso, donde está settings.gradle.kts.
3. Deja que termine la sincronización de Gradle. El primer uso puede requerir Internet.
4. Configura el SDK instalado en ESE computador. El ZIP no incluye local.properties ni
   las carpetas de caché del equipo anterior. Android Studio puede generar la ruta local.
5. Conserva inicialmente las versiones recibidas del proyecto. No aceptes migraciones
   de dependencias como primer paso para resolver un error.
6. Usa un emulador o dispositivo API 36 o superior. Pulsa Run para iniciar la aplicación.
7. Ejecuta las pruebas y los recorridos manuales descritos en PRUEBAS_Y_ALCANCE.txt.

CUENTAS PARA PROBAR
Escribe el nombre de cuenta en el campo de correo. Contraseña para TODAS: 123.
visitante  -> catálogo, fichas, favoritos, rutas y solicitudes propias.
docente    -> el mismo recorrido de consulta y planificación de salidas educativas.
guia       -> disponibilidad por día, solicitudes con guía y aceptación/rechazo.
encargado  -> edición del recinto 1 y sus eventos.
admin      -> edición de todos los recintos, coordinación de visitas y reinicio de la demo.
La cuenta original admin / 123 se conserva. Son perfiles de demostración, no seguridad real.
Para cambiar de cuenta, entra a Perfil > Cerrar sesión. El acceso vuelve a solicitarse
si Android termina el proceso; los datos guardados se conservan.

DATOS LOCALES
SharedPreferences + JSON, sin dependencias nuevas. No se guardan contraseñas.
Se conservan los cambios de los cinco perfiles en una misma instalación para ensayar
la coordinación. El ZIP lleva el código, no los datos creados en un teléfono.
Desinstalar la app o borrar su almacenamiento puede eliminar los datos de prueba.
Los tests instrumentados usan un almacén distinto, para no borrar la demostración.

MAPAS Y TIEMPOS
El mapa es un esquema ilustrativo, sin GPS ni distancias geográficas reales.
Tiempo de referencia: 25 minutos por recinto + 15 entre paradas. No usar para viajes reales.
La disponibilidad del guía es por jornada completa, con un recorrido por día.
Los horarios de recintos se editan como texto; no se comprueban automáticamente contra
la hora de la visita. Se exige que los recintos estén en estado ABIERTO al solicitar y confirmar.
